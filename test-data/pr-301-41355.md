feat(studio): endpoint to retrieve incident status

## Body
Incident status banners/alerts should be automatically determined from the status page, rather than being manually configured.

Adds a new endpoint, /api/incident-status, to return information about active incidents. This information is fetched from the StatusPage API. The endpoint is cached to reduce number of third-party API requests.

**Testing**

Because Vercel deployment protection is on, the API can't be accessed on the preview site. You'll have to test locally.
