## Title
feat: Add GH workflow for authorizing Vercel deploys

## Body
This PR adds a GH action which will automatically approve all Vercel builds when it runs. This is to avoid manual work where a Supabase team member has to manually approve all deploys on each new commit.

The Vercel builds have Git Fork protection which means builds are not run automatically when the PR is coming from GH fork. This is done to protect the environment variables in Vercel (bad actor might console.log `OPENAI_API_KEY` and abuse it). Builds have to be manually approved by a person
