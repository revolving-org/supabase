## Body
When `parse_regex()` fails, `parsed` will not be `null` but an empty object, such that `parsed != null` will be true but the `parsed.level` lookup will produce `null`.

Later, `upcase!()` will fail on the `null` value.

Instead, just directly check `parsed.level`.
