## Title
docs: Add version requirement note for Windsurf MCP client

## State
merged

## Body
Adds a warning note to the Windsurf MCP client configuration advising users to use version `0.1.37` or higher.
This version includes the fix for [Protected Resource Metadata Discovery (RFC 9728)](https://github.com/geelen/mcp-remote/pull/193) in `mcp-remote`, which is required for MCP authorization compliance

Follows the same pattern used for the Gemini CLI version requirement note.
