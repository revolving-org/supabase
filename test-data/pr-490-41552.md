## Title
feat(etl): Implement batch rollback

## State
merged

## Body
This PR implements a new overhauled UX around table restarts. The rationale for implementing this is that many customers have a lot of tables that they want to replicate and we want to give them the possibility to batch restart a series of tables in case they fail. We also want to give them the option to individually restart a table that is not in failing state.

The PR uses the new `rollback-tables` endpoint and implements a new more sophisticated UI for allow all kinds of restarts.
