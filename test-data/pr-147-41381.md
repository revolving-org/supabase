## Title
Prevent ForeignRowSelector from firing multiple saves when clicked

## State
merged

## Body
## Context

When updating a foreign row reference in the Table Editor directly from the grid, when clicking on the row multiple times, the `onSelect` prop in `ForeignRowSelector` gets triggered multiple times too, which in this case results in the `SidePanelEditor` calling `onSaveForeignRow` multiple times, and multiple success toasts will hence show up
