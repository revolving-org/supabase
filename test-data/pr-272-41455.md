## Title
ai-commands: standardize user-facing errors in clippy

## State
review

## Body
## Problem
The clippy command mixes generic `Error` throws with structured `UserError` /
`ApplicationError` instances, which makes some user-input failures harder
to handle consistently.

## Changes
- Replaced generic `Error` throws for invalid message role and missing user
  message with `UserError`
- Preserved existing behavior while improving error structure

## Why
Using consistent, typed errors improves DX and makes failures easier to
debug and handle programmatically.
