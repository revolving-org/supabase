## Title
Fix(studio): prevent importing rows as CSV to protected entities

## State
open

## Body
Fixes #41358 

## What kind of change does this PR introduce?

Bug fix

## What is the current behavior?

Users able to add row data as CSV to any empty entity

## What is the new behavior?

Users can't import CSV rows to any table, and instead they are shown the relevant UI message depending on the case, if:

1. The entity is not a table.
2. The entity schema is protected.
3. User is not allowed to edit tables.
