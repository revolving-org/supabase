## Body
This PR adds the integration with the new validation endpoints which allow to validate things before a pipeline is started. This is done to reduce many of the problems that customers have when configuring pipelines.

In addition, it removes the primary key alert since it's now handled by the validation endpoint and improves the copy around publications.
